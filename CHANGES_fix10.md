# iResponse fix10: what changed

1. Incident screens: responder card with name, photo/initial, station and live location (distance + ETA to the report).
2. Live responder map on the incident screen for citizen, responder and admin (pin moves, route line, Live tag, Recenter). Works for reports with no map pin (SMS SOS): the map centres on the responder.
3. Messages: red count on the Messages buttons, on the first bottom tab, and a phone notification per conversation.
4. Review or close report (admin): closest responders listed first (tap to assign), then Under review / Resolved / Cancelled. Reports with no pin measure distance from the assigned station.
5. My reports: "New update" marker on each report, red count on the My reports tab, and a phone notification when a responder or admin accepts or updates a report.
6. Map search: type letters, get every station whose name (or a word in it) starts with them, matching letters highlighted, matching pins lit up on the map. Same prefix match in the Stations list.
7. Profile picture: tap the avatar on Profile or use Settings > Profile > Edit photo (take photo, gallery, remove).
